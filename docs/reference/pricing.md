# 価格表

すべての料金は **円建て・従量課金** です。月額固定プランはありません。

## 無料クレジット

電話番号認証を完了すると無料クレジットが付与されます。

## チャージ

- 最低チャージ額: **¥3,000**
- 最大チャージ額: **¥1,000,000**
- 支払方法: クレジットカード (Stripe)
- 入金後、即座に残高に反映

## 残高アラート

- 残高が **¥500 未満** になるとメールで通知
- 残高が **¥0 以下** になると API 呼び出しが停止 (HTTP 402)
