# モデル一覧

完全なモデルIDは **`プロバイダ/モデル名`** 形式です（例: `alibaba/qwen-turbo`、`deepseek/deepseek-v4-flash`）。
利用時は **`プロバイダ`** を base_url のパスに、**`モデル名`（スラッシュ以降）** をリクエスト本文の `model` に指定します。
下表の「モデルID」列はこの完全IDです。

```bash
curl https://api.lykuro.ai/v1/models \
  -H "Authorization: Bearer lk_live_YOUR_KEY"
```

## モデルを探す

機能（画像入力・Function Calling・思考モードなど）やモデル名で絞り込めます。モデルを選ぶと、その**API パラメータとサンプルコード**（curl / Python / Node.js）が表示されます。

### サンプル — テキスト生成

```bash
curl https://api.lykuro.ai/deepseek/v1/chat/completions \
  -H "Authorization: Bearer lk_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "Pythonでクイックソートを書いてください"}]
  }'
```

```python
from openai import OpenAI

client = OpenAI(api_key="lk_live_YOUR_KEY", base_url="https://api.lykuro.ai/deepseek/v1")

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "Pythonでクイックソートを書いてください"}],
)
print(response.choices[0].message.content)
```

### サンプル — Thinking mode

```python
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "√2 が無理数であることを証明してください"}],
    extra_body={"thinking": {"type": "enabled", "budget_tokens": 5000}},
)
print(response.choices[0].message.reasoning_content)  # 思考過程
print(response.choices[0].message.content)             # 最終回答
```

### サンプル — ストリーミング

```python
stream = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "日本の歴史を教えてください"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

# Alibaba（Qwen / Wan ほか）

Alibaba Model Studio の **International（シンガポール）** デプロイ単価です（USD建て）。思考モード対応モデルは出力単価が **非思考／思考** で異なります（思考は思考連鎖＋回答の合算）。

下表の **「API例」** 列の **[API参照]** ボタンから、各モデルの **API パラメータ** と **サンプルコード**（curl / Python / Node.js）を確認できます。ベースURLは用途別に次の通りです。

- OpenAI互換（テキスト/ビジョン/Omni/埋め込み）: `https://api.lykuro.ai/alibaba/compatible-mode/v1`
- リアルタイム（WSS）: `wss://api.lykuro.ai/alibaba/api-ws/v1/realtime`
- DashScope ネイティブ（画像/動画/音声合成/音声認識/リランク）: `https://api.lykuro.ai/alibaba/api/v1`
